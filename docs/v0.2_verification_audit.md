## Mathematical findings

1. **End-mass fraction defect corrected in this audit.** The prior finite path applied `upper_mass_fraction` to total mass, then subtracted tether mass only from the lower end. This contradicted §6.1’s fixed end masses. It now partitions `m_tot - ρL_f` between both end bodies, with tether mass represented separately.
2. **Dynamic tension remains partial.** §9.2 describes a single scalar tension path, while the implementation reports independently inferred upper and lower endpoint values. Their difference is a useful midpoint-mass-model diagnostic, but it is not a solved single-link tension network; no equality claim is made.
3. **Angular-momentum discrepancy is unresolved.** The §8 co-rotating velocity term adds an `ωI_cm` contribution as length grows, while §7 fixes CM angular momentum on the initial circular orbit. The resulting total Earth-centered angular momentum is therefore not exactly conserved for several specified benchmarks (for example BM-DEP-003: ~`1.36e-7`, BM-DEP-005: ~`5.44e-7` relative residual). The `1e-8` §11 gate is now recorded and exposes this mismatch. Resolving it requires a specification decision: change the CM/tip kinematics to conserve total angular momentum, or explicitly model/account for actuator-orbit angular-momentum exchange. This audit does not substitute either model.

## Remaining gaps

Nonzero reel acceleration, mechanical-energy diagnostics, an explicit solved single-scalar dynamic tension network, caller-independent minimum sampling, benchmark quantitative acceptance thresholds, a resolved angular-momentum model inconsistency, and independent aerospace review remain outstanding. No flight, mission, safety, or scientific validation claim is supported by this audit.
